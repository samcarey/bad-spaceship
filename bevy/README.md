# Bevy

This is the [Bevy](https://bevyengine.org)
implementation of [Bad Spaceship](https://gitlab.com/sccarey/bad-spaceship).

## Current State

So far, you can control a floating cube as your character using your keyboard (W, S, D, A) and mouse.
You can also adjust the 3rd-person zoom with your mouse wheel/scroll, all the way in to 1st-person view.

This demonstrates the latest features using the Rapier physics engine!
