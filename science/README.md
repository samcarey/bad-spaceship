# **SCIENCE!!**

This section is for experimenting with stuff before actually trying to integrate it into the game.
The research section.

Some things may use Python and maybe [Jupyter](https://jupyter.org/),
so you'll probably want to reuse the Python environment used for the process of building the site,
described in the root [README.md](/README.md),
and then run `pip install -r science/requirements.txt`.
Then, if you wan to open a `.ipynb` file (Jupyter Notebook),
either run `jupyter notebook` and follow the printed link in your browser to open the file,
or just open the file in VS Code which will do the same thing automatically within the IDE.
